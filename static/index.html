    The command for what you see

    What do the letters in Permissions mean?

    -rwxr-xr-- is read in four parts. The first character is the type (- file, d folder, l link). Then three groups of three: owner, group, everyone else. In each group r = read, w = write, x = run (or enter, for a folder), and - = not allowed.

    So -rwxr-xr-- means: the owner can read, change and run it, the group can read and run it, and everyone else can only read it. Click any item to see this spelled out.

    Click a file to preview it, or a folder to open it. Everything here is read-only: nothing can be changed or deleted.
